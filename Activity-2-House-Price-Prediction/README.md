# Activity 2: Simple House Price Prediction

## Unit
Unit II – Supervised Learning: Regression

## Objective
To develop a Linear Regression model
for predicting house values.

## Dataset
California Housing Dataset

## Algorithm
Linear Regression

## Input Feature
MedInc (Median Income)

## Target Variable
MedHouseVal (Median House Value)

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

## Tasks Completed
- Dataset inspection
- Feature selection
- Data visualisation
- Train-test splitting
- Linear Regression training
- Prediction
- MAE, MSE, RMSE and R2 evaluation
- Actual vs predicted visualisation
- New value prediction
